About this conversion

This web app ports the workbook’s `RunMICoach` VBA macro into JavaScript and embeds the workbook’s prompt worksheets as static data.

What is included

  • All 39 workbook worksheets as browser data.
  • The prompt repositories used by the original macro.
  • The conversation state machine, classification rules, ask-tell-ask logic, transcript, and scorecard.
  • Downloadable session log and scorecard text files.

Important limitation

Browsers cannot run Excel VBA directly. This is a functional JavaScript reimplementation, not an Excel/VBA runtime. It intentionally avoids server-side storage to reduce privacy risk.
